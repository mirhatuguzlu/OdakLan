# OdakLan

Anti-doomscroll focus RPG. Telefona dokunmadan geçen her dakika şehrini büyütür; Odak Klanı ile arkadaşlarınla birlikte odaklanırsın.

- `mobile/` — Flutter uygulaması (`flutter run`, `flutter test`, `flutter analyze`)
- `web/` — Tanıtım sitesi, Next.js + Tailwind + Motion (`npm run dev`)

Sitenin özellik listesi ve yol haritası `web/src/content/features.ts` dosyasından gelir; uygulamadaki her adımla birlikte güncellenir.
